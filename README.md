# Earl Grey theme

Heavily WIP implementation of Earl Grey color theme onto Zed.

Website: https://earl-grey.halt.wtf

## Usage

This extension hasn't been submitted yet, so currently you have to install it manually.
Do either of these two methods.

**Method 1** - raw JSON
1. Download the JSON file within the `themes` folder.
2. Create a `themes` subdirectory (if you haven't already) within your Zed configuration directory (typically `~/.config/zed` for MacOS and Linux).
3. Move the JSON file into the aforementioned directory.
4. Restart Zed, and enter Theme Selector from the command palette.

**Method 2** - install dev extension
1. Clone this repository into a folder.
2. Open Command Palette, run something like `zed: install dev extension`, and pick the folder you cloned the repository into.

## Note

There are minor differences between this and the official VSCode extension both as a result of Zed having more limited palette customisation, as well as a few tweaks to make a few more sections readable.
